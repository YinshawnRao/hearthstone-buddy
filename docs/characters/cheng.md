# 澄

澄是炉石 Buddy 的默认同伴，一位原创的成年女性角色。画面是本仓库里重新绘制的分层 SVG：头发高光、眼睛、服装和披肩都由代码路径组成。

- 不是暴雪角色，不使用炉石立绘，也不是从网上抓来的同人图。
- 不是 Live2D，也没有动作捕捉。眨眼和呼吸是 CSS。
- 授权：这段原创 SVG 以与仓库相同的方式提供给本项目使用，可替换。以后的委托绘制或 Live2D 必须另附许可证，不能把现在的 SVG 说成已经是那些格式。
- 炉石卡图仍来自 HearthstoneJSON，和澄的画不是同一份授权。见 README 的卡牌数据一节。

角色表在 `apps/desktop/src/shared/characters.ts`。新增角色时增加一条记录和对应渲染组件，不要改分析编号的规则。
