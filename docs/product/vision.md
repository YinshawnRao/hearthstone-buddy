# 炉石 Buddy

炉石 Buddy（Hearthstone Buddy）是一个桌面陪伴：一位原创的成年动漫女性角色和你一起看炉石，用气泡说出下一手建议。她不操作鼠标，不注入游戏，也不是暴雪的官方产品。

她只使用已经能从 Power.log 和本地规则里确定的信息。对手手牌、未翻开的奥秘和之后的抽牌保持未知。通用策略是启发式，不是当前环境的卡组攻略，也不承诺胜率。

## 阶段

每个阶段都有交付、非目标和验收。没有日期承诺。

### 阶段 0：规则与真实对局

交付：Power.log 解析、合法动作、卡牌目录对照、本地分析和可选模型。

非目标：完整模拟发现、随机、亡语、光环和奥秘。

验收：没有密钥时演示局面仍能给出带编号的建议；非法动作编号会被拒绝。

### 阶段 1：启动器、轻量角色和语音适配

交付：启动器、Windows 上对 Hearthstone.exe / Battle.net 的交接、透明置顶的 2D 角色、表情、眨眼和呼吸、气泡模式、可取消的本地语音适配。

非目标：Live2D、已签名安装包、在 macOS 上声称已经验证能启动炉石。

验收：启动失败时启动器还在，并写明原因。只开陪伴不会被说成已经进入对局。气泡在同一局面不重复朗读。快照变化会取消上一次语音。

### 阶段 2：更高质量的角色和本地语音

前提：性能和许可证都确认之后。

交付：可替换的委托绘制或 Live2D 资源，以及更好的本地语音。

非目标：把现在的 SVG 说成已经是 Live2D。

### 阶段 3：可选的回顾与个性化

交付：可清空的回顾导出、主题，以及默认关闭的遥测开关。

非目标：情绪操控、未经同意的上传、伪造对手信息。
