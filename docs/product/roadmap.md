# 路线图

对应 `docs/product/vision.md`。这里只记录顺序和验收，不写日历。

1. 阶段 0 已在主分支：日志、规则、卡牌目录、模型接口。
2. 阶段 1 的第一切片在本分支：启动器、角色澄、气泡、Windows 启动交接、可选语音适配。真机 Windows 合成和全屏游戏覆盖还没有在这台 Linux 环境里证实。
3. 阶段 2 再考虑委托绘制或 Live2D，以及更稳的本地语音。资源必须能替换，协议先于模型。
4. 阶段 3 才做回顾、主题和可选遥测。遥测默认关闭。

未完成的战术缺口仍然存在：发现、随机、抉择、连击、法强、亡语、光环和奥秘效果都没有被当成已经模拟。
